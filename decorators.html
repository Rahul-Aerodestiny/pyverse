Decorators & Context Managers

Extend functions with reusable wrappers and manage resources cleanly using Python context managers.

Decorators

Decorators wrap functions to add behavior without modifying the original code. They are often used for logging, timing, and authorization.

def timer(func): import time def wrapper(*args, **kwargs): start = time.time() result = func(*args, **kwargs) print(f"Elapsed: {time.time() - start:.4f} seconds") return result return wrapper @timer def compute(): return sum(range(100000)) compute()

Context Managers

Context managers simplify setup and cleanup logic using the `with` statement.

with open('example.txt', 'w', encoding='utf-8') as file: file.write('Hello from context manager')

Custom Context Manager

class managed_file: def __init__(self, filename): self.filename = filename def __enter__(self): self.file = open(self.filename, 'w', encoding='utf-8') return self.file def __exit__(self, exc_type, exc_value, traceback): self.file.close() with managed_file('custom.txt') as f: f.write('Custom manager!')
