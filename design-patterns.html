Design Patterns

Learn Pythonic implementations of proven design patterns that improve structure and maintainability.

Singleton Pattern

The Singleton pattern ensures a class has only one instance and provides a global point of access to it.

class Singleton: _instance = None def __new__(cls, *args, **kwargs): if cls._instance is None: cls._instance = super().__new__(cls) return cls._instance

Factory Pattern

The Factory pattern abstracts object creation and lets the code choose which concrete class to instantiate.
