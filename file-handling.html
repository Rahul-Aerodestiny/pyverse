File Handling

Work with files safely and effectively in Python using context managers and built-in I/O tools.

Opening Files

Use the built-in `open()` function to read and write files. Always close files or use `with` to ensure resources are released.

with open('data.txt', 'w', encoding='utf-8') as file: file.write('Hello, PyVerse!') with open('data.txt', 'r', encoding='utf-8') as file: content = file.read() print(content)

Common File Modes

  • 'r': read-only
  • 'w': write (overwrite)
  • 'a': append
  • 'x': create new file
  • 'b': binary mode

Working with CSV & JSON

Python includes built-in libraries for common file formats:

  • csv for comma-separated values
  • json for structured data interchange
