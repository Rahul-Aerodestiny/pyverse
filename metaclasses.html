Metaclasses & Metaprogramming

Discover how Python creates classes at runtime, and how metaprogramming can simplify recurring patterns.

What are Metaclasses?

Metaclasses are the classes of classes. They control class creation and allow developers to inject behavior when the class is defined.

class UpperAttrMeta(type): def __new__(cls, name, bases, dct): uppercase_attrs = {k.upper(): v for k, v in dct.items() if not k.startswith('__')} return super().__new__(cls, name, bases, uppercase_attrs) class Person(metaclass=UpperAttrMeta): name = 'Rahul' print(hasattr(Person, 'name')) print(hasattr(Person, 'NAME'))

When to Use Metaclasses

  • Creating ORM-style model classes
  • Enforcing class conventions
  • Automatic registration and validation
